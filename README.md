## Project Description

**PSU-Sphere** is a web backend application tailored for Palawan State University to streamline student organization management[cite: 1]. Built on Django, it models complex relationships between academic units (Colleges & Programs), student entities, and campus student organizations[cite: 1]. It features a customized administrative interface for rapid searching, filtering, and data management, alongside custom seed scripts to populate large-scale sample records during development[cite: 1].

---

## Features

* **Relational Academic Data Models:** Structured mapping for Colleges, Academic Programs, Organizations, Students, and Memberships[cite: 1].
* **Customized Django Admin Panel:** Customized list displays, search vectors, and inline relationship views for easy site administration[cite: 1].
* **Automated Data Seeding:** Integrated CLI command leveraging `Faker` to quickly generate realistic student IDs, localized names, and organization rosters[cite: 1].
* **Auditing Fields:** Standardized base model tracking creation and modification timestamps[cite: 1].
