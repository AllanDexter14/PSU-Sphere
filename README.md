## Project Description

**PSU-Sphere** is a Django-based web application tailored for Palawan State University to manage student organizations, colleges, academic programs, students, and organization memberships[cite: 1]. It provides an organized way to store and manage campus entities directly through the customized Django admin interface[cite: 1].

---

## Features

* **Colleges & Academic Programs:** Manage colleges and their corresponding degree programs[cite: 1].
* **Student Information:** Record student records with full name details, student IDs, and assigned academic programs[cite: 1].
* **Student Organizations & Memberships:** Manage campus organizations and track active memberships alongside the exact date a student joined[cite: 1].
* **Enhanced Admin Tools:** Custom Django Admin panel configured to search students by last/first name, filter by college, and display each student's academic program directly within membership records[cite: 1].
* **Automated Data Seeding:** Command-line script powered by `Faker` to quickly generate sample data for testing and development[cite: 1].
